## Hi there, I'm Udo

Software engineer from Hamburg. I work on architecture, requirements and quality. My professional core is .NET and WPF, and lately I've been adding Rust, TypeScript and Python.

I started to write my very first lines of code back in 1998 when I borrowed a book about the C language from the library. It was not a big success, I have to admit. After a week of struggling I decided that this was just insane and gave it back. It took me another two years to give it another try and finally start that journey which I am still on.

I am deeply interested in how things work and how to turn them into a model, an architecture and finally into some code.

### Interests

- Document databases: they blew my mind when I first learned that not everything has to be relational and schema-bound.
- AI agents: harnesses and memory, and how to make them useful beyond a chat window.
- UI/UX: software should be enjoyable to use.

### Projects

- **[trunkdb](https://github.com/u-schmidt/trunkdb)**: an embedded document database in Rust. One file, no server, no schema.
- **[eidolon](https://github.com/u-schmidt/eidolon)**: a topic memory system for AI agents. It segments conversations into topics and keeps memory fragments instead of transcripts, retrieved by meaning, tags, people and time.
